'@arki/failure': minor

New package: typed expected failures with no wrapper and no runtime. `defineFailure(code, { data, message, status, remediation })` names a failure once; calling the definition makes a frozen, branded failure value that a function returns like any other value, so its return type is inferred as `Value | Failure<…>` and the compiler makes every caller check. Message templates (`'no post {id}'`) are checked against the data schema. Adds `isFailure` (a promise is a type error), exhaustive `match`, `recover` (partial handling that removes the handled codes from the type), `orThrow` with `UnexpectedFailure`, `attempt` for code that throws, `revive` for failures that went through JSON, `findCause` for cause chains, `partition`, `collect`, `assertNever`, `FailureOf`, `SuccessOf`. Entries: `@arki/failure/orpc` (`errorMap`, `orThrowRpc`) and `@arki/failure/eslint` (the `must-use` rule for discarded failures). The data schema is any Standard Schema; the core has no dependencies.
