Stored values and shutdown no longer leak raw errors. The Postgres plugin now ends the query pool and the session pool even when the first `end()` throws, and reports every failure (an `AggregateError` when both fail). The `plainDate` and `instant` codecs, and the SQLite `instant`, throw an `UnexpectedFailure` carrying the new `StoredValueUnreadable` failure (`db.stored_value_unreadable`) instead of a raw `RangeError` for `infinity`, BC dates, malformed text, `NaN` and out-of-range milliseconds. `listenOnPool` rejects its start with `ListenUnavailable` (`db.listen_unavailable`, raw pool error as `cause`), and a throwing `onState` observer is logged instead of rejecting the start or breaking the listener. `runTransaction`, `runTransactionOnce`, `createUnitOfWork` (and so `transactionalProcedure`) and `listenOnPool` emit default `db.*` spans, and every observed operation records `db.operations` and `db.operation.duration`. Removed the dead `DbRuntimeLocalError`, `DB_RUNTIME_LOCAL_ERROR_CODES` and `DbRuntimeLocalErrorCode`. `createIdFactory` is marked deprecated. Migration: replace imports of the removed names with the canonical `DataDirInUse` failure; catch `UnexpectedFailure` where you caught `RangeError` from a temporal read.
