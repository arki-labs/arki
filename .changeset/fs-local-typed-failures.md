'@arki/fs': minor
---

The local file helpers return typed storage failures instead of throwing. `readFile` is now async and resolves to the text, `StorageNotFound` for a missing path, `StorageRejected` for an unknown encoding or a refused read, `StorageUnavailable` or `StorageCancelled` (it takes an optional `signal`). `writeToTheFileEnd` resolves to nothing, `StorageRejected` when nothing was written, or `StorageWriteUncertain`. `deleteAsync` resolves to the deleted paths, `StorageRejected` for a path outside the working directory or a permission error, or `StorageWriteUncertain`. `deleteSync` returns the same paths and failures as `deleteAsync`, synchronously. `glob` resolves to the matched paths, `StorageCancelled`, or `UnexpectedDefect` for an invalid option set. `globIterate` yields the paths and never throws: its return value is `undefined` or that same failure. `globStream` is now a web `ReadableStream` of paths that never errors: a failure arrives as its last chunk. `ProgressData` stays a type re-exported from `del`. Each records an `fs.local.*` span and metric. Migration: `await` `readFile` and check the result with `isFailure` before using it; check the result of the other helpers the same way; read `globIterate`'s return value and check `globStream` chunks with `isFailure`.
