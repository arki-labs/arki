'@arki/live': minor
---

Live queries M2: hub, endpoint, Dot. `@arki/live/http` adds `liveEndpoint`, the `GET /api/live` server-sent-events stream: a bad cursor (400 E004), a refused `authorize` (401 E005) and a hub without its listener (503 E003, `retry-after`) are answered before any stream header; `hello` carries the part of the manifest the grant allows; `change` frames keep only granted tables and only the txids of transactions that wrote one of them, and a frame with none is skipped whole, so a client cannot see writes on tables it cannot read; after `maxAgeMs` (5 minutes) the stream sends `bye`. `@arki/live/dot` adds `liveQueries`, a Dot plugin that verifies triggers at boot (E002), listens at start, releases the listen client on stop or rollback, and publishes `live` and `liveRoutes`. `@arki/live/orpc` adds `liveManifest` (nested routers; procedures without live meta skipped; bad meta is E001) and `@arki/live` adds `liveTables`. The hub's `stop()` now settles once for every caller and only after the source stopped, also while `start()` is still running; a stopped hub refuses `start()`. New optional peers: `@arki/http`, `@arki/dot`. Each `change` frame now names exactly the transactions that wrote its own tables (before: the whole batch, on its last frame); the hub's feed adds `txidsByTag` for filtering. Breaking: the Zod schemas are no longer exported. `@arki/live` exports plain types (`TableTag`, `LiveMeta`, `LiveManifest`, `LiveCursor`, `LiveEvent`, `LiveLimits`) and the runtime checks `parseLiveEvent` and `parseLiveCursor`, so no public type ties a consumer to Zod.
