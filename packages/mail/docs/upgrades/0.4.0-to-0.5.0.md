# 0.4.0 to 0.5.0

`mailOutboxPlugin`, `MailOutboxPluginOptions` and `mailJobs` move from `@arki/mail/dot` to the new `@arki/mail/outbox` entry. `@arki/mail/dot` keeps only `mail`.

Why: queued mail needs `@arki/journal`, an optional peer. While `@arki/mail/dot` imported the outbox, an app that only sent mail still had to install the journal, or it failed at start with `Cannot find package '@arki/journal'`. Now `@arki/mail/dot` loads without it.

Change the import in an app that queues mail:

```ts skip="needs a Dot app with a journal"
// before
import { mail, mailJobs, mailOutboxPlugin } from '@arki/mail/dot';

// after
import { mail } from '@arki/mail/dot';
import { mailJobs, mailOutboxPlugin } from '@arki/mail/outbox';
```

An app that uses only `mail` changes nothing, and it can drop `@arki/journal` if nothing else needs it.
