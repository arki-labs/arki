# Upgrade @arki/contracts 0.3.0 to 0.4.0

Nobody has to change code: this release only adds exports. Read on if you write JSON columns by hand.

## What changed

- `@arki/contracts/drizzle` exports `JsonStorableSchema` and `jsonStorageSchema`: the schema rule `jsonColumn` requires and the refined schema it stamps on the column. `@arki/db`'s column kit uses the same pair for `c.json(name, schema)`, so insert and select schemas check kit JSON columns exactly as they check `jsonColumn`.

## Public API changes

Added to `@arki/contracts/drizzle`:

- `JsonStorableSchema`: the type of schema `jsonColumn` accepts.
- `jsonStorageSchema`: the refined schema `jsonColumn` stamps on a column.

Nothing was removed or renamed.

## Steps

1. Upgrade the package:

   ```sh
   bun add @arki/contracts@^0.4.0
   ```

2. Optional: if you built your own JSON column helper, reuse the pair instead of restating the rule.

   ```ts
   // before: a hand-written check next to the column
   // after
   import { jsonStorageSchema } from '@arki/contracts/drizzle';
   ```

## Verify

```sh
bun run typecheck
```

It passes with no changes to your code.
