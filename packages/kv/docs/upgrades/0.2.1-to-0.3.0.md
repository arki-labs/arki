# Upgrade @arki/kv 0.2.1 to 0.3.0

Act if your CI or lint runs import `@arki/kv`: its env check (`defineEnv`) no longer skips there. Act too if you use `@arki/kv/redis/idempotency`, which needs `@arki/http`. Everything else in 0.3.0 is additive.

## What changed

- Breaking: `defineEnv` (which `@arki/kv` uses for `KV_URL` and the Redis variables) validates in every environment. `CI` and lint runs no longer skip it.
- `@arki/http` is now an optional peer dependency of `@arki/kv`. It is only imported by `@arki/kv/redis/idempotency`. In 0.2.1 only `@arki/dot` was a peer.
- New: `@arki/kv/redis/idempotency` exports `redisResponseCache(redis, options)`, a Redis `ResponseCache` for `@arki/http/idempotency`.
- New: `kv.optional(options)` in `@arki/kv/dot`. With no URL it publishes `kv` as `null` and opens no client.
- New: `probe: true` and `probeTimeoutMs` (default 5000) on `kv()` and `kv.optional()`. A failed probe fails boot with `ARKI_KV_PLUGIN_E002` (`KV_PLUGIN_ERROR_CODES.probeFailed`).
- New: `kv()` publishes through a `provides` factory, so `cache.provides.kv` is a typed handle before boot.
- Docs: `AGENTS.md`, `llms.txt`, an agent guide and `@fix` / `@verify` tags on every error code now ship in the package.

## Public API changes

- Added: `@arki/kv/redis/idempotency` with `redisResponseCache` and `RedisResponseCacheOptions`.
- Added: `kv.optional`, `KvDotOptions.probe`, `KvDotOptions.probeTimeoutMs`, `KV_PLUGIN_ERROR_CODES.probeFailed`.
- Changed: `kv()` is no longer declared as `Plugin<EmptyShape, KvServices>`. Its return type is now inferred from `plugin()` and exposes `provides.kv`.
- Unchanged: `KV_PLUGIN_ERROR_CODES.urlNotConfigured` (`ARKI_KV_PLUGIN_E001`), the `url`, `namespace` and `rateLimitPrefix` options, and `services.kv`.

## Steps

1. Make sure your CI and lint jobs have valid env values. Validation used to be skipped there. For a build stage that runs without secrets, set `SKIP_ENV_VALIDATION=1` (exactly `1`).

   ```sh
   # before: CI skipped validation implicitly
   # after: build stage without secrets
   SKIP_ENV_VALIDATION=1 bun run build
   ```

2. If you use `@arki/kv/redis/idempotency`, install `@arki/http` next to `@arki/kv` 0.3.0. The peer range is `workspace:*` in the repo; see `package.json` of the published version. Read `@arki/http/docs/upgrade-idempotency.md` first.

3. Optional: where Redis may be absent, use `kv.optional` and handle `null`.

   Before: boot failed with `ARKI_KV_PLUGIN_E001` when no URL was set.

   ```ts skip="before: the 0.2.1 API"
   .use(kv(() => ({ url: env.KV_URL, namespace: 'pizzeria' })))
   ```

   After: `kv` is `KV | null`.

   ```ts skip="after: 0.3.0 with the @arki/dot 0.7 builder"
   import { defineApp } from '@arki/dot';
   import { kv } from '@arki/kv/dot';

   const env = { KV_URL: process.env.KV_URL };

   export const app = defineApp('pizzeria').use(kv.optional(() => ({ url: env.KV_URL, namespace: 'pizzeria' })));
   ```

## Verify

```sh
bun run typecheck
```

Run it in your app. It must pass with no errors. If you annotated the type of `kv()` by hand, it will show here.
