# Upgrade @arki/math 0.1.0 to 0.2.0

Parsers return, builders throw.

- `parseNumber`, `parseDecimal` (`@arki/math/parse`) and `fromBase` (`@arki/math/integer`) return the value or a failure instead of throwing: `InvalidNumber` (`math.invalid_number`) for text that is not a number, `NumberOutOfRange` (`math.number_out_of_range`) past 10 000 digits, an exponent or scale past ±10 000, or the float range of a `number`. Replace `try`/`catch (NumberFormatError)` with `if (isFailure(result))` from `@arki/failure`, or match `InvalidNumber.is(result)`.
- New `parseComplex(text)` in `@arki/math/complex` returns the same failures. `complex('3+4i')` stays the throwing builder.
- `MATH_PARSE_FAILURES` lists the failures; `MathParseFailure` is their union.
- Builders (`decimal`, `ratio`, `complex`) and arithmetic throw as before. A builder's over-limit text throws `ResourceLimitError` with a new message.
- `lcm` on bigints throws `ResourceLimitError` past 100 000 result digits, like `combinations`.
- `@arki/failure` is now the one runtime dependency.
