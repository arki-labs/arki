# @arki/native-ui API reference

Every exported value, grouped by import path. Types are not listed. The components are React Native Reusables style wrappers over `@rn-primitives`, styled with NativeWind. The root path `@arki/native-ui` re-exports every value listed below, so each name can be imported from the root or from its own path.

## @arki/native-ui

- Everything in the sections below.

## @arki/native-ui/components/accordion

- `Accordion`: The accordion with expandable sections.
- `AccordionContent`: Accordion with expandable sections part: the content area.
- `AccordionItem`: Accordion with expandable sections part: one item.
- `AccordionTrigger`: Accordion with expandable sections part: the element that opens or toggles it.

## @arki/native-ui/components/alert

- `Alert`: The inline alert box.
- `AlertDescription`: Inline alert box part: the description text.
- `AlertTitle`: Inline alert box part: the title.

## @arki/native-ui/components/alert-dialog

- `AlertDialog`: The modal dialog that asks for a decision.

## @arki/native-ui/lib/cn

- `cn`: Merges Tailwind class names with clsx for conditions and tailwind-merge so later classes win.

## @arki/native-ui/lib/colors

- `darkenColor`: Makes a hex color darker by a percent (0 to 100).
- `hexToRgba`: Turns a hex color into an rgba string with an alpha from 0 to 1.
- `isValidHexColor`: Tells whether a string is a valid hex color.
- `lightenColor`: Makes a hex color lighter by a percent (0 to 100).

## @arki/native-ui/lib/utils

- `debounce`: Delays a function call and returns it with a `cancel()` for the pending call.
- `formatFileSize`: Formats a byte count as readable text.
- `getInitials`: Returns the initials of a full name, at most 2 characters.
- `truncate`: Cuts a string to a length.
