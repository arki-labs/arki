# Interpolation outcomes

`interpolate` and `StringValue.interpolate` return `MissingValue` when an own key is absent or its value is undefined. Success remains a string or `StringValue`. Narrow the result before consuming it.

```ts run
import { isFailure } from '@arki/failure';
import { interpolate, MissingValue } from '@arki/string/interpolate';

const result = interpolate('Hello {{ name }}', {});
if (isFailure(result)) {
  if (!MissingValue.is(result)) throw new Error('Unexpected failure definition');
} else {
  result.toUpperCase();
}
```

Replace `missing: 'throw'` with `missing: 'fail'`. The default is `fail`; there is no throw compatibility option. Invalid policy values from JavaScript callers fail an invariant instead of silently dropping text. The retired `STRING_ERROR_CODES.missingValue`/E005 diagnostic is removed. Match `MissingValue.is(result)` or `result.code === 'string.missing_value'` instead of catching `StringError` for absent data. The failure exposes no template, placeholder key or supplied values.

Explicit `keep` and `empty` policies retain their behavior; null still renders as empty text. Malformed placeholder syntax remains `StringError` E004. This change adds no dependencies or telemetry spans to local text interpolation.
