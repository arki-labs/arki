# 0.1.1 to 0.2.0

Sleep and concurrency now return owned outcomes. Replace catches of `ARKI_ASYNC_E002` and `ARKI_ASYNC_E004` with checks of `Cancelled.is(outcome)` and `Deadline.is(outcome)`. A callback rejection becomes `UnexpectedDefect`; its original exception remains the private cause. An all-rejected race retains its input-ordered AggregateError privately. Empty race and invalid delay/concurrency definitions remain static misuse and may reject.

`all` and `mapConcurrent` keep fulfilled Failure values as explicit array/tuple elements. `race` still chooses the first fulfilled value, including a Failure. Its heterogeneous tasks now retain their exact union. Successful values remain unwrapped. Check an owned outcome before reading or destructuring its success value. At a real foreign exception boundary use the canonical failure bridge explicitly; do not add a private wrapper that recreates the old sleep API.

Retired exception codes E002/E003/E004 and the `abortedError`, `cleanupFailed` and `timedOut` exports are removed. `AsyncError` now describes static E001/E005 misuse and no longer carries legacy finalizer errors. Scope cleanup failures retain exact original members through ScopeFailed.

Concurrency calls emit one default operation span and duration metric. Libraries install no SDK. Task callbacks activate the owner context; private causes, payloads and abort reasons are not exported. Raw clocks and scheduling substrates have no per-timer span.
