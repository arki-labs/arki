# Upgrade @arki/money 0.1.0 to 0.2.0

Parsers return, builders throw. A function that reads outside values now returns a failure instead of throwing. Your own literals still go through builders that throw.

## What changed

| Before (throws)                            | After (returns)                                    | Failure codes                                                             |
| ------------------------------------------ | -------------------------------------------------- | ------------------------------------------------------------------------- |
| `Money.parse(text)`                        | `Money \| failure`                                 | `money.invalid_text`, `money.unknown_currency`, `money.input_too_large`   |
| `Money.fromJSON(value)`                    | `Money \| failure`                                 | the above plus `money.invalid_shape`                                      |
| `parseMoney(text, currency, options)`      | `Money \| failure`                                 | the above plus `money.rounding_necessary`, `money.unsupported_locale`     |
| `createMoneyParser(currency, options)`     | `MoneyParser \| UnsupportedLocale`                 | `money.unsupported_locale`                                                |
| `parser.parse(text)`                       | `Money \| failure`                                 | `money.invalid_text`, `money.input_too_large`, `money.rounding_necessary` |
| `parser.tryParse(text)`                    | removed: use `parser.parse(text)`                  |                                                                           |
| `fromProviderUnits(units, currency, rule)` | `Money \| failure`                                 | `money.provider_amount`, `money.out_of_range`, `money.unknown_currency`   |
| `fromStripeAmount(amount, currency)`       | `Money \| failure`                                 | the above                                                                 |
| none                                       | `Currency.parse(code)`, `Currency.parseNumeric(n)` | `money.unknown_currency`                                                  |

## How to upgrade

Handle the failure where outside input enters:

```ts
import { isMoneyFailure, Money } from '@arki/money';

export function readPrice(body: { price: unknown }) {
  const price = Money.fromJSON(body.price);
  if (isMoneyFailure(price)) return { status: price.status, error: price.code, fix: price.remediation };
  return { price };
}
```

Where the value is your own data and a bad value is a bug, throw with `orThrow` from `@arki/failure`:

```ts
import { orThrow } from '@arki/failure';
import { Money } from '@arki/money';

export function totalOf(event: { data: { total: { amount: string; currency: string } } }) {
  return orThrow(Money.fromJSON(event.data.total));
}
```

Replace `parser.tryParse(text)` with `parser.parse(text)` and check `isMoneyFailure`. A form shows `failure.remediation`.

## What did not change

`money()`, `Money.of`, `Money.fromMinor`, `Currency.of`, `Currency.fromNumeric`, `stripeRule`, `toProviderUnits`, `toStripeAmount` and all arithmetic still throw the same `MathError` subclasses. Drizzle columns still throw on bad stored values.
