# Upgrade @arki/http 0.2.1 to 0.3.0

Act if you declare routes with `route.*()`, return a `Response` from a handler, or use `SchemaLike`. Skip it if you only use `listen`, `derive` and plain `route.get` calls with `output`.

## What changed

Breaking:

- `params`, `headers` and `query` are records with one field per key, not one `z.object`.
- A bare schema only decodes. Two-way fields use `codec(decode, encode)`.
- A route with no `output` answers 204. Returning a `Response` needs `output: raw()`.
- Contracts take any Standard Schema, not only zod. OpenAPI needs each schema's JSON Schema, or throws `ARKI_HTTP_E013`.
- A 400 lists every failing field as `where.key: message`.
- Output is encoded, so a one-way `.transform()` on an output schema fails with 500.
- Removed `SchemaLike`. `RouteContract` now takes `<TPath, TDef>`.

Added (no action needed):

- `check` hook on routes and SSE routes (issues answer 400).
- `responses` and `reply(status, body, { headers? })`, optional last path segment (`/orders/:id?`).
- `failures: [...]` on a contract, `RouteFailure<typeof contract>`.
- `createClient` from `@arki/http/client`, with `policy`, `retryOn`, `timeoutMs`.
- New subpaths `@arki/http/idempotency` and `@arki/http/webhooks` (idempotency, `ResponseCache`, webhook verification, typed failures). See the CHANGELOG.
- `@arki/http/public-fetch` has a new API and error code `ARKI_HTTP_E430`. See the CHANGELOG.
- `endpoints(core, build, { contracts })` in `@arki/http/dot`.
- `instancePath` on `http(...)` for feature instances.

## Public API changes

- Added exports: `codec`, `optional`, `raw`, `reply`, and the types `Codec`, `Wire`, `Field`, `Fields`, `FieldsOf`, `Optional`, `Reversible`, `ValueOf`, `WireValue`, `CheckResult`, `ErasedInput`, `RawOutput`, `Reply`, `RouteDef`, `SseDef`, `ResponseSchemas`, `RouteFailure`.
- Added subpaths: `@arki/http/client`, `@arki/http/idempotency`, `@arki/http/webhooks`.
- Removed: `SchemaLike`. `RouteInput` moved to the contract types.
- Changed: `RouteContract<TPath, TQuery, TBody, TOutput>` is now `RouteContract<TPath, TDef>`. `RouteHandler`, `SseHandler`, `HandlerResult` follow.
- New error codes: `ARKI_HTTP_E011` (bad contract, from `route.*()`), `E012`, `E013`, `E408`, `E410`-`E413`, `E420`-`E422`, `E430`, `E510`, `E511`.

## Steps

1. Turn `query`, `headers` and `params` into records. Wrap a key that may be missing in `optional(...)`. Header names must be lower-case.

   Before:

   ```ts skip="before: the 0.2.1 API"
   route.get('/orders/:id', { query: z.object({ page: z.coerce.number().optional() }), output: Order });
   ```

   After:

   ```ts
   import { optional, route } from '@arki/http';
   import { z } from 'zod';

   const Order = z.object({ id: z.string(), total: z.number() });

   export const getOrder = route.get('/orders/:id', {
     id: 'getOrder',
     params: { id: z.string() },
     query: { page: optional(z.coerce.number()) },
     output: Order,
   });
   ```

2. Replace any zod `z.codec` or transform that must encode (for example ISO string and `Date`) with `codec(decode, encode)`. Use a codec for output schemas too; a one-way `.transform()` there now fails.

   Before: output was any `z.ZodType`, for example:

   ```ts skip="before: the 0.2.1 API"
   output: z.codec(z.iso.datetime(), z.date(), { decode: s => new Date(s), encode: d => d.toISOString() })
   ```

   After:

   ```ts
   import { codec, route } from '@arki/http';
   import { z } from 'zod';

   export const getStamp = route.get('/stamp', {
     id: 'getStamp',
     output: codec(
       z.iso.datetime().transform(text => new Date(text)),
       z.date().transform(date => date.toISOString()),
     ),
   });
   ```

3. Give a route that returns a `Response` `output: raw()`. A route with no `output` now answers 204 and its handler returns nothing.

   Before: no output, and the handler returned a `Response`:

   ```ts skip="before: the 0.2.1 API"
   route.get('/file', { id: 'file' })
   ```

   After:

   ```ts
   import { raw, route } from '@arki/http';

   export const file = route.get('/file', { id: 'file', output: raw() });
   ```

4. Make optional path placeholders match: `/orders/:id?` needs `params: { id: optional(...) }`, and the reverse. A mismatch throws `HttpConfigError` `ARKI_HTTP_E011` when the route is declared.

5. Replace removed types. Use `StandardSchemaV1` where you used `SchemaLike`. Rewrite `RouteContract<TPath, TQuery, TBody, TOutput>` as `RouteContract<TPath, TDef>`.

6. If a schema has no JSON Schema (OpenAPI throws `ARKI_HTTP_E013`), wrap it with `withJsonSchema(schema, jsonSchema)` from `@arki/schema`. Zod and arktype need nothing.

7. If you tested 400 messages, update them to the `query.page: ...` form. A schema that throws now answers 500.

## Verify

```sh
bun run typecheck
```

Run it in the app that uses `@arki/http`. It must finish with no type errors. A leftover `SchemaLike` or old `query: z.object(...)` shows up as an error. Then run your tests: 400 messages, 204 answers and output encoding changed at runtime.
