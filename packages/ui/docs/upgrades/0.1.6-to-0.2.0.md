# Upgrade @arki/ui 0.1.6 to 0.2.0

Anyone who imports `@arki/theme` or `@arki/react-hooks` must switch to `@arki/ui/theme` and `@arki/ui/hooks/*`; apps that use neither can skip those steps. Apps that import `@arki/ui/design-system` or the `@arki/design-systems` navigation stylesheet follow step 3.

Coming from 0.1.5 (the last published version)? Also apply the 0.1.6 changes listed below. 0.1.6 was never published, so 0.1.5 goes straight to 0.2.0.

## What changed

- 0.1.6: the `exports` map lists one entry per public module instead of a `"./*"` wildcard. Every import path that worked before still works.
- 0.1.6: the `.` and `./toast` entries are removed. They pointed at files that do not exist, so importing them already failed. Use per-component subpaths such as `@arki/ui/button` and `@arki/ui/sonner`.
- `@arki/theme` is now `@arki/ui/theme` and `@arki/ui/theme/script`. The code is the same. `@arki/theme` is deprecated on npm ("Moved to @arki/ui/theme") and gets no more releases. `@arki/ui` no longer depends on it.
- New option `themeClasses`: a theme can set several classes on the root element, and changing the theme removes them all.
- `@arki/react-hooks` is now `@arki/ui/hooks/*`, one subpath per hook. The code is the same. `@arki/ui` no longer depends on `@arki/react-hooks`; that package is retired.
- `@arki/ui/design-system` is removed, and `@arki/ui` no longer depends on `@arki/design-systems`. The components read the standard shadcn token names, so any shadcn-compatible theme works (the README shows a minimal setup). `@arki/design-systems` is retired: it gets no more releases.
- The page navigation crossfade moved from `@arki/design-systems/transitions/nav.css` to `@arki/ui/styles/nav.css`.

## Public API changes

- New subpath `@arki/ui/theme`: `ThemeProvider`, `useTheme`, and the types `Theme`, `ResolvedTheme`, `ThemeProviderProps`, `UseThemeReturn`.
- New subpath `@arki/ui/theme/script`: `themeScript`, `themeDetectionFn`, `THEME_STORAGE_KEY`, and the type `ThemeDetectionOptions`.
- New option `themeClasses` on `ThemeProvider` and on `themeScript` / `themeDetectionFn`: `{ 'candle-dark': ['dark', 'candlelight'] }`.
- New subpaths `@arki/ui/hooks/<name>` for `async-memo`, `copy-to-clipboard`, `debounce`, `hotkeys`, `is-client`, `local-storage`, `long-press`, `media-query`, `pagination`, `timeout`, `toggle`, `touch`, `use-swipe-gesture`, `use-touch-feedback` and `use-viewport`. Each exports what the same-named `@arki/react-hooks` file exported.
- New subpath `@arki/ui/styles/nav.css`: the navigation view-transition stylesheet.
- Removed: `@arki/ui/design-system` (`DESIGN_SYSTEM_IDS`, `DESIGN_SYSTEMS`, `getDesignSystemById`, `getDesignSystemByIdSafe`, `isDesignSystemId`, `parseDesignSystemId`, `designSystemIdSchema`, `defaultUiDesignSystemId`, `resolveUiDesignSystemId` and the types `DesignSystemId`, `DesignSystemMetadata`).
- Removed: the `.` and `./toast` entries (0.1.6). They never resolved.
- Removed dependencies: `@arki/theme`, `@arki/react-hooks` and `@arki/design-systems`.

## Steps

1. Replace the theme package. Skip this step if you do not import `@arki/theme`.

   ```bash skip="shell commands for the app being upgraded"
   bun remove @arki/theme
   bun add @arki/ui@^0.2.0
   ```

   Change every import. These names moved to `@arki/ui/theme`: `ThemeProvider`, `useTheme`, `Theme`, `ResolvedTheme`, `ThemeProviderProps`, `UseThemeReturn`. These moved to `@arki/ui/theme/script`: `themeScript`, `themeDetectionFn`, `THEME_STORAGE_KEY`.

   ```ts skip="before and after fragment of a migration"
   // before
   import { ThemeProvider, useTheme } from '@arki/theme';
   import { themeScript } from '@arki/theme/script';
   // after
   import { ThemeProvider, useTheme } from '@arki/ui/theme';
   import { themeScript } from '@arki/ui/theme/script';
   ```

2. Replace the hooks package. Skip this step if you do not import `@arki/react-hooks`.

   ```bash skip="shell commands for the app being upgraded"
   bun remove @arki/react-hooks
   ```

   Each hook has its own subpath.

   ```ts skip="before and after fragment of a migration"
   // before
   import { useDebouncedValue } from '@arki/react-hooks/debounce';
   // after
   import { useDebouncedValue } from '@arki/ui/hooks/debounce';
   ```

3. Leave `@arki/design-systems`. Skip this step if you import nothing from it or from `@arki/ui/design-system`.

   ```css skip="before and after fragment of a migration"
   /* before */
   @import '@arki/design-systems/transitions/nav.css';
   /* after */
   @import '@arki/ui/styles/nav.css';
   ```

   Keep your tokens: either stay on the last published `@arki/design-systems` stylesheets, or paste a shadcn theme into your global stylesheet (see the README quick start). If you imported ids or helpers from `@arki/ui/design-system`, keep that list in your own code: `@arki/ui` no longer reads it.

4. Optional: use `themeClasses` when one theme needs several root classes.

   ```ts skip="before and after fragment of a migration"
   // before: one class per theme, named after the theme
   <ThemeProvider themes={['light', 'dark', 'candle-dark']}>
   // after: candle-dark sets both classes, and a switch removes both
   <ThemeProvider
     themes={['light', 'dark', 'candle-dark']}
     themeClasses={{ 'candle-dark': ['dark', 'candlelight'] }}
   >
   ```

5. If you list dependencies in a file such as `arki.deps.json`, remove `@arki/theme` and `@arki/react-hooks` from it.

## Verify

Run this from the app root. It finds nothing when no old import is left:

```bash skip="shell commands for the app being upgraded"
git grep -nE "@arki/(theme|react-hooks|design-systems)|@arki/ui/design-system" -- . ; echo "exit $?"
```

It prints `exit 1`, because no line matched. Then check that the new subpaths load:

```bash
bun -e "const t = await import('@arki/ui/theme'); const s = await import('@arki/ui/theme/script'); const d = await import('@arki/ui/hooks/debounce'); console.log(Object.keys(t).sort().join(', ')); console.log(Object.keys(s).sort().join(', ')); console.log(Object.keys(d).sort().join(', '))"
```

It prints:

```text
ThemeProvider, useTheme
THEME_STORAGE_KEY, themeDetectionFn, themeScript
useDebouncedCallback, useDebouncedState, useDebouncedValue
```
