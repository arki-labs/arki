OrderCancelled

PaymentSettled
  written by command charge-payment  [workflow checkout@1 node charge; payments: payments/entrypoints/webhook.ts]
  fold payment  [same transaction]
  workflow checkout@1 waits as "settled" at node confirm  owner payments; deps none; retry per step

PaymentRefunded
  written by command refund-payment  [workflow checkout@1 node charge (undo); payments: payments/entrypoints/webhook.ts]
  fold payment  [same transaction]

Workflow checkout@1
  node charge  runs command charge-payment
  node charge  undoes with command refund-payment
  node confirm  waits for PaymentSettled as "settled"
  node notify.push.release  runs command cancel-order
  opaque steps (may run commands, not drawn): notify.mail.send-mail, log

  opaque steps (may run commands, not drawn): hold
