# Upgrade @arki/testing 0.3.0 to 0.4.0

You must act if you import `@arki/testing/e2e`, `@arki/testing/ai/playwright`, `@arki/testing/services/mailpit`, `/postgres` or `/redis`, or `IntegrationTester` or `initTester` from `@arki/testing/server/*`, or if you pass a bad number to a helper; everyone else can skip it.

## What changed

- `@arki/testing` renames five export entries so the layers check treats them as adapter entries. Only the import path changes. Every exported name stays the same.
  
  - `@arki/testing/e2e` is now `@arki/testing/playwright`.
  - `@arki/testing/ai/playwright` is now `@arki/testing/playwright/ai`.
  - `@arki/testing/services/mailpit` is now `@arki/testing/containers/mailpit`.
  - `@arki/testing/services/postgres` is now `@arki/testing/containers/postgres`.
  - `@arki/testing/services/redis` is now `@arki/testing/containers/redis`.
- Unknown values are checked by schemas (A-39), and numbers the helpers cannot honour are the invariant failure `ARKI_FAILURE_E008` before any work runs.
  
  - `isTimestamp`, `assertTimestamps`, `assertPaginationValid`, `assertDeepPartialMatch`, `assertArraySorted`, the stack manifest and the Ollama answer shapes use zod schemas. New type `PaginatedResponse` (what `assertPaginationValid` narrows to); `Timestamp`, `Verdict` and `CheckedClaim` are now inferred from their schemas (same shape; `Verdict` and `CheckedClaim` fields are no longer `readonly`).
  - `assertPaginationValid` now checks `total`, `nextCursor` and `hasMore` types whenever they are present. `assertArraySorted` refuses `NaN` and an `Invalid Date` key instead of passing.
  - `epochNanoseconds` / `epochMilliseconds` of an `Invalid Date` throw the invariant failure (was a raw `RangeError` from `BigInt(NaN)`).
  - Invariant failure for: `createMany` count not a whole number ≥ 0; `measurePerformance`, `assertPerformance` and the tracker's `measure` `maxMs` not finite ≥ 0; `benchmarkQuery` / `comparePerformance` iterations not a whole number ≥ 1, and `comparePerformance` with no operations (was a raw `TypeError`); `assertTimestampRecent` `withinSeconds` not finite ≥ 0; `createJudge` / `createEmbedder` `timeoutMs` not a whole number from 1 to 2^31 - 1, `seed` not whole, `maxTokens` not ≥ 1 (a bad timeout read as `OllamaUnavailable`); `mailbox().waitFor` `timeoutMs` not finite ≥ 0; `dumpTable` `limit` not a whole number ≥ 0.
  - `e2eTest` `cron.run` reports a failed status as `CRON_FAILED` before reading the body, and a body that is not JSON as `CRON_BAD_BODY` (was a raw `SyntaxError`).
- `IntegrationTester`, `initTester` and their types moved to `@arki/auth`. The entries `@arki/testing/server/integration-tester` and `@arki/testing/server/tester-builder` are gone: import every name from `@arki/auth/testing/integration-tester` instead. The names and types are unchanged, so only the import path changes. `@arki/testing` no longer depends on `@arki/auth` in any form (it was a dev dependency and an optional peer), which breaks the package cycle `@arki/testing -> @arki/auth -> @arki/mail -> @arki/journal -> @arki/admin -> @arki/testing`. `@arki/db` and `@arki/kv` are no longer dependencies; only the moved code used them.
  
  Docs: README `## Public imports`, `docs/agent-guide.md`; the integration tester guide moved to `@arki/auth` (`docs/integration-tester.md`).
- New entry `@arki/testing/otel` with `captureSpans()`. It installs an in-memory tracer provider and meter
  provider as the OpenTelemetry globals for one test (plus an `AsyncLocalStorage` context manager when none
  is registered) and returns `finished`, `named(name)`, `childrenOf(span)`, `collectMetrics()`, `reset()`
  and `[Symbol.dispose]`, so `using spans = captureSpans()` restores the earlier providers. Each captured
  span carries its finished `parent`. `@opentelemetry/sdk-trace-base` and `@opentelemetry/sdk-metrics` are
  new dependencies; `@opentelemetry/api` is an optional peer.
  
  Docs: `docs/otel.md`, README public imports, failure and limits lines, agent guide task.
  no demo impact: test tooling, no demo uses it.

## Steps

1. Change the five renamed import paths. Only the path changes.

   Before:

   ```ts skip="before: the 0.3.0 API"
   import { e2eTest } from '@arki/testing/e2e';
   import { mailpit } from '@arki/testing/services/mailpit';
   ```

   After:

   ```ts skip="the 0.4.0 import paths; the example needs Playwright and Docker"
   import { e2eTest } from '@arki/testing/playwright';
   import { mailpit } from '@arki/testing/containers/mailpit';
   ```

   Use the same rule for the others: `@arki/testing/ai/playwright` becomes `@arki/testing/playwright/ai`, `/services/postgres` becomes `/containers/postgres`, and `/services/redis` becomes `/containers/redis`.

2. Import `IntegrationTester` and `initTester` from `@arki/auth`. Add `@arki/auth` to your own dependencies, because `@arki/testing` no longer brings it.

   Before:

   ```ts skip="before: the 0.3.0 API"
   import { initTester } from '@arki/testing/server/tester-builder';
   ```

   After:

   ```ts skip="the 0.4.0 import path; the example needs Docker"
   import { initTester } from '@arki/auth/testing/integration-tester';
   ```

3. Check numbers you pass to the helpers. A count, limit, timeout or iteration number the helper cannot honour now fails with the invariant failure `ARKI_FAILURE_E008` before any work runs. The "What changed" list names each argument. A `NaN` or an `Invalid Date` key in `assertArraySorted` now fails the check instead of passing.

4. If you read the result of `e2eTest` `cron.run`, handle `CRON_FAILED` (a failed status) and `CRON_BAD_BODY` (a body that is not JSON). Before, a bad body threw a raw `SyntaxError`.


## Verify

```sh
bun run typecheck
```

Run it in your app. It passes only when no import path names a removed entry. Then run your tests and look for any test that relied on a raw `RangeError`, `TypeError` or `SyntaxError` from a helper.
